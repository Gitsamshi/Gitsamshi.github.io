THE RL DIFF MAP

the atomic unit is the diff, not the paper

A paper is one substrate + one operator: on X, swap component C for C′, get effect E. The sibling paper map indexes by what a paper is about — so retrieval returns lookalikes and you can only interpolate. This map indexes by which move it made. Group by operator and a move becomes transferable: take the abstract form of RNN→Transformer (kill the serial dependency, go fully parallel) and ask what it does on another substrate. The hard, dirty step is diff against what — pick the wrong baseline and the diff is noise — so baselines are first-class and confidence is labelled.
